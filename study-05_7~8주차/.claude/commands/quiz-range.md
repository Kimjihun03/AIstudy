---
description: 지정한 번호 범위의 퀴즈 문제를 검토하고 난이도와 정답 분포를 확인합니다.
argument-hint: <시작 번호> <끝 번호>
---

$1번부터 $2번까지의 퀴즈 문제를 검토해 주세요. 시작 번호와 끝 번호를 모두 포함합니다.

1. 첫 번째 인자 `$1`을 시작 번호, 두 번째 인자 `$2`를 끝 번호로 사용합니다. 개별 치환이 지원되지 않아 해당 표기가 그대로 남아 있으면 `$ARGUMENTS`의 첫 번째와 두 번째 값을 각각 시작 번호와 끝 번호로 해석합니다.
   - 정확히 두 개의 양의 정수가 필요하며 시작 번호는 끝 번호 이하여야 합니다.
   - 누락, 추가 인자, 숫자가 아닌 값 또는 역순 범위이면 올바른 사용법을 안내하고 검토를 중단합니다. 임의로 범위를 바꾸지 않습니다.
2. 현재 프로젝트의 퀴즈 데이터 파일을 찾고 문제의 `id`를 기준으로 범위를 선택합니다. 배열 위치나 화면에 무작위로 표시되는 순번을 문제 번호로 사용하지 않습니다. 의존성, 빌드 결과물, Git 내부 파일 및 명령어 파일은 검색 대상에서 제외합니다.
   - 선택한 문제를 번호순으로 검토합니다. 범위 안에 누락되거나 중복된 ID가 있으면 보고합니다.
   - 요청 범위와 실제 검토한 ID 및 문제 수를 명시합니다. 대상 문제가 없거나 데이터 파일을 찾지 못하면 그 사실을 안내하고 중단합니다.
3. `CLAUDE.md`의 검증 지침을 따르며 각 문제의 본문, 선택지, 정답과 해설을 함께 검토합니다.
   - 정답이 하나로 결정되는지, 정답 인덱스가 선택지 범위 안의 정수인지, 해설과 정답이 일치하는지 확인합니다.
   - '가장', '최초', '최대' 등의 표현에는 비교·측정 기준이 있는지, 시간과 지리적·분류적 범위가 명확한지 확인합니다.
   - 중복 선택지, 정답을 쉽게 노출하는 단서, 불필요하게 혼동을 주는 문구를 찾고 구체적인 수정안을 제시합니다.
   - 의심스러운 사실은 독립적인 출처 두 개 이상으로 교차 검증하고 출처를 표시합니다. 확인할 수 없으면 추측하지 말고 '확인 필요'로 표시합니다.
4. 각 문제의 난이도를 '하 / 중 / 상'으로 평가하고 근거를 짧게 설명합니다. 별도의 대상 독자가 지정되지 않으면 일반 상식 퀴즈 이용자를 기준으로 평가하며, 응답 통계에 근거한 실측이 아닌 추정임을 명시합니다.
   - 하: 널리 알려진 기초 지식을 바로 떠올리면 풀 수 있음.
   - 중: 구체적인 지식이나 유사한 선택지의 구분, 간단한 추론이 필요함.
   - 상: 전문적·세부적인 지식이나 여러 단계의 추론이 필요함.
   - 모호한 문구나 오류로 풀기 어려운 문제는 난이도와 별도로 품질 문제를 표시합니다.
5. 검토 결과를 '문제 ID / 카테고리 / 문제 요약 / 정답 번호와 내용 / 추정 난이도와 근거 / 발견한 문제와 수정 제안' 표로 제공합니다. 수정이 필요한 항목에는 파일 경로와 줄 번호도 표시합니다.
6. 난이도별 문제 수와 비율을 표로 요약합니다. 비율의 분모는 실제 검토한 문제 수로 합니다. 평가할 수 없는 문제는 '평가 불가'로 따로 집계해 합계가 일치하도록 합니다.
7. 정답 위치 분포를 확인합니다.
   - `answerIndex`는 0부터 시작하므로 보고할 정답 번호는 `answerIndex + 1`입니다. 원본 데이터의 선택지 순서를 기준으로 집계합니다.
   - 각 정답 번호별 문제 수와 비율을 표로 표시하고, 한 번도 정답이 아닌 위치도 0건으로 표시합니다.
   - 유효하지 않은 정답 인덱스는 분포에서 제외하고 해당 ID와 제외 건수를 별도로 보고합니다. 비율의 분모는 유효한 정답을 가진 문제 수이며, 0개이면 비율을 '계산 불가'로 표시합니다.
   - 선택지 개수가 다른 문제들은 선택지 개수별로 나눠 집계합니다.
   - 특정 번호에 정답이 몰리거나 번호순으로 같은 정답 위치가 반복되는지 실제 수치와 해당 ID를 근거로 설명합니다. 소수 문제의 불균형만으로 오류라고 단정하지 않습니다.
   - 앱에서 선택지를 섞는 경우 원본 데이터의 분포와 실제 플레이 화면의 정답 위치 분포가 다를 수 있음을 설명합니다.
8. 우선 수정할 문제와 난이도·정답 분포의 개선 제안을 간결하게 정리합니다. 데이터 파일은 수정하지 않고 검토 결과만 보고합니다.

사용 예시:
- `/quiz-range 1 10`: ID 1번부터 10번까지 검토
- `/quiz-range 15 15`: ID 15번 문제만 검토
