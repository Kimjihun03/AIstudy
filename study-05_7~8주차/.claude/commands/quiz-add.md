---
description: 카테고리와 난이도에 맞는 새 퀴즈를 검증한 뒤 기존 데이터 형식으로 추가합니다.
argument-hint: <카테고리> <난이도: 하|중|상>
---

카테고리 `$1`, 난이도 `$2`에 맞는 새 퀴즈 문제 1개를 작성하고 프로젝트의 퀴즈 데이터에 추가해 주세요.

1. 인자를 해석합니다.
   - 첫 번째 인자 `$1`은 카테고리, 두 번째 인자 `$2`는 난이도입니다. 개별 치환이 지원되지 않아 표기가 그대로 남으면 `$ARGUMENTS`의 첫 번째와 두 번째 값을 사용합니다.
   - 정확히 두 개의 인자를 받습니다. 난이도는 '하 / 중 / 상'을 사용하고 '쉬움 / 보통 / 어려움'도 각각 같은 값으로 처리합니다.
   - 인자가 누락되거나 난이도가 유효하지 않으면 사용 예시를 안내하고 파일을 수정하지 않습니다.
2. 먼저 `CLAUDE.md`, `js/questions.js` 및 퀴즈 데이터를 사용하는 코드를 읽어 현재 검증 지침과 데이터 구조를 확인합니다.
   - 카테고리는 현재 `CATEGORIES`에 등록된 값을 사용합니다. 일치하는 값이 없으면 사용 가능한 카테고리를 안내하고 중단합니다.
   - 기존 문제 전체를 살펴보고 문장만 바꾼 문제나 같은 사실을 묻는 중복 문제를 피합니다.
3. 일반 상식 퀴즈 이용자를 기준으로 요청한 난이도의 문제를 작성합니다.
   - 하: 널리 알려진 기초 지식을 바로 떠올리면 풀 수 있는 문제.
   - 중: 구체적인 지식이나 비슷한 선택지의 구분, 간단한 추론이 필요한 문제.
   - 상: 전문적·세부적인 지식이나 여러 단계의 추론이 필요한 문제.
   - 난이도는 추정이며, 모호한 문구나 말장난으로 난이도를 높이지 않습니다. 오답은 그럴듯하되 명확히 틀려야 합니다.
4. 저장 전에 `CLAUDE.md`의 검증 가이드라인을 반드시 적용합니다.
   - 정답이 하나뿐인지 확인합니다. 다른 해석이 가능하면 문제 본문에 조건을 명시합니다.
   - '가장 큰', '최초', '최대' 등 비교·최상급 표현에는 측정 지표와 비교 기준을 명시합니다.
   - 변할 수 있는 정보는 기준 연도나 날짜를, 필요한 경우 지리적·분류적 범위를 명시합니다.
   - 의심스러운 사실은 독립적인 출처 2개 이상으로 교차 검증합니다. 논란이 있는 내용은 주류 학설을 기준으로 조건을 명시합니다.
   - 정답과 해설이 일치하고 나머지 선택지가 해당 조건에서 오답인지 확인합니다. 중복 선택지와 정답을 노출하는 단서가 없어야 합니다.
   - 필요한 사실 확인을 완료하지 못한 문제는 저장하지 않습니다. 검증 가능한 다른 소재로 대체하고, 그래도 해결되지 않으면 미추가 사유를 보고합니다. 출처나 검증 결과를 만들어 내지 않습니다.
5. 검증을 통과한 문제를 `js/questions.js`의 `QUESTIONS` 배열 내 해당 카테고리 구역에 추가합니다. 기존 형식과 들여쓰기, 따옴표, 쉼표 스타일을 유지합니다.
   - 객체 구조: `{ id, category, question, choices, answerIndex, explanation }`
   - `id`: 전체 기존 문제의 최대 ID에 1을 더한 중복 없는 정수. 기존 문제의 ID는 변경하지 않습니다.
   - `category`: 입력한 기존 카테고리.
   - `question`: 조건과 범위가 명확한 한국어 문제.
   - `choices`: 서로 다른 선택지 문자열 정확히 4개.
   - `answerIndex`: 0부터 3까지의 정수. `choices[answerIndex]`가 정답이어야 합니다.
   - `explanation`: 정답의 이유와 필요한 기준을 설명하는 간결한 한국어 해설.
   - 현재 스키마에 없는 `difficulty` 등의 필드는 추가하지 않습니다. 요청 난이도는 출제와 결과 보고에 반영합니다.
   - 정답 위치는 기존 분포를 참고해 지나치게 한 번호에 몰리지 않도록 정합니다. 정답 위치를 바꾸면 인덱스도 함께 맞춥니다.
6. 저장 후 변경 내용을 확인합니다.
   - JavaScript 구문 오류가 없는지, 문제 수가 정확히 1개 늘었는지 확인합니다.
   - ID 중복 여부, 카테고리 등록 여부, 필수 필드와 선택지 4개, 정답 인덱스와 해설의 일치를 확인합니다.
   - 기존 문제와 앱 동작에 불필요한 변경이 없는지 확인합니다. 실행할 수 없는 검사는 수행한 것처럼 보고하지 않습니다.
7. 결과로 수정한 파일, 새 문제 ID와 카테고리, 요청 난이도와 판단 근거, 문제·선택지·정답·해설을 보여 줍니다. 정답 번호는 사용자에게 1부터 4까지로 표시합니다. 적용한 검증 기준, 실제 확인한 출처와 검사 결과도 간결하게 보고합니다.

사용 예시:
- `/quiz-add 과학 중`
- `/quiz-add 한국사 어려움`
