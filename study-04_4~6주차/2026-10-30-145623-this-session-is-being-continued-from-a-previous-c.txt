  구현된 기능:

  1. ✅ 자동 카테고리 분류
     - 업무: "회의", "프로젝트", "보고", "발표", "클라이언트" 등
     - 공부: "공부", "숙제", "시험", "코딩", "알고리즘" 등
     - 개인: 위 키워드가 없으면 기본값
  2. ✅ 실시간 감지
     - 입력 필드에 텍스트를 타이핑할 때마다 자동으로 카테고리 검사
     - 매칭되는 키워드가 있으면 select 값이 즉시 변경
  3. ✅ 시각적 피드백
     - 카테고리별 배경색이 select에 적용됨 (업무: 주황색, 공부: 초록색, 개인:
       보라색)
     - 사용자가 자동 분류됨을 한눈에 인지 가능
  4. ✅ 사용자 제어
     - select를 수동으로 변경 가능 (자동 분류 무시)
     - 입력 내용에 따라 자동으로 업데이트됨

  테스트:
  1. index.html 새로고침
  2. "회의" 입력 → select가 "업무"로 변경되고 주황색으로 표시
  3. "공부" 입력 → select가 "공부"로 변경되고 초록색으로 표시
  4. "장보기" 입력 → select가 "개인"으로 유지되고 보라색으로 표시
  5. select 수동 변경 가능

  자동 분류는 한글 키워드만 감지합니다. 필요시 키워드를 추가할 수 있습니다.

● 카테고리 자동분류는 app.js의 세 부분으로 이뤄져 있습니다.

  1. CATEGORY_KEYWORDS (app.js:8-11)
  - 카테고리별 키워드 목록입니다.
  - work에는 회의, 프로젝트, 업무, 마감 등이 있고, study에는 공부, 숙제, 시험,
    코딩 등이 있습니다.
  - personal은 키워드가 없고, 기본값으로 쓰입니다.

  2. autoDetectCategory(text) (app.js:215-223)
  - 입력 문자열을 toLowerCase()로 소문자로 바꿉니다.
  - work, study 순서로 키워드를 확인하고, 키워드가 하나라도 포함되면(includes)
    그 카테고리를 반환합니다.
  - 어느 키워드에도 해당하지 않으면 'personal'을 반환합니다.
  - 객체 순서대로 검사하기 때문에 work가 먼저입니다. 예를 들어 "회의 준비
    공부"는 work로 분류됩니다.

  3. input 이벤트 리스너 (app.js:241-247)
  - 할 일 입력창에 글자를 입력할 때마다 실행됩니다.
  - 입력값이 비어 있지 않으면 autoDetectCategory() 결과를
    #categorySelect.value에 넣습니다.
  - 이렇게 정해진 카테고리가 addTodo()에서 그대로 저장됩니다.

  알아둘 점
  - 사용자가 선택창을 직접 바꿔도, 다음 글자를 입력하면 자동 분류가 그 선택을
    덮어씁니다.
  - includes로 부분 일치를 검사하기 때문에 "팀"처럼 짧은 키워드는 "팀장" 같은
    다른 단어에도 걸립니다.
  - 입력창을 비우면 선택창 값은 마지막 상태로 남습니다.
  - 이 파일에는 선택창 색이 바뀌는 코드가 없습니다. style.css의 [value="..."]
    선택자는 동작하지 않아서, 색 적용은 web_version/app.js에서만 고쳤습니다.

  수동 선택이 유지되도록 고치거나, 원본 app.js에도 색 적용을 넣을 수 있습니다.
