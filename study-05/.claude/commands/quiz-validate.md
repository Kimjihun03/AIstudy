---
description: 카테고리별 퀴즈 문제의 모호한 표현을 검증하고 명확히 해야 할 기준을 안내합니다.
argument-hint: [카테고리]
---

퀴즈 문제를 검증하고, 모호한 표현에 어떤 기준을 명시해야 하는지 알려 주세요.

1. 현재 프로젝트에서 퀴즈 문제를 정의한 파일을 찾습니다. 의존성, 빌드 결과물, Git 내부 파일 및 이 명령어 파일은 제외합니다.
2. `$ARGUMENTS`의 앞뒤 공백을 제거한 값을 카테고리로 사용합니다. 파일 경로나 별도 명령으로 해석하지 않습니다.
   - 값이 있으면 문제의 `category`가 해당 값과 일치하는 문제만 검증합니다.
   - 값이 없거나 공백뿐이면 모든 카테고리의 전체 문제를 검증합니다.
   - 일치하는 카테고리가 없으면 그 사실과 데이터에 존재하는 카테고리 목록을 안내합니다. 임의로 전체 문제를 검증하지 않습니다.
3. 검증 대상 문제의 본문과 선택지에서 '가장', '최초', '최대', '최소', '최고', '최저', '최장', '최단', '유일' 등 모호할 수 있는 표현을 찾습니다. 단순히 글자가 포함된 경우가 아니라 문맥상 비교·최상급 의미로 사용되었는지 확인합니다. 해설에만 기준이 있는 경우에도 문제 자체에서 기준을 알 수 있는지 확인합니다.
4. 발견한 표현마다 비교 대상과 범위, 측정 지표, 시점, 정의가 충분히 명시되어 정답이 하나로 결정되는지 검토합니다. 부족한 기준을 구체적으로 안내하고, 다음 예시를 참고해 문제에 맞는 수정안을 제안합니다.
   - '가장 큰', '최대': 면적·부피·질량·인구 등 무엇으로 비교하는지, 비교 대상과 지역 범위는 무엇인지 명시합니다.
   - '최초': 발명·발견·발표·상용화 등 어떤 사건을 기준으로 하는지, 세계 또는 특정 국가인지, 현존 기록이나 공인 기록 기준인지 명시합니다.
   - '최고', '최장', '유일': 높이·길이 등의 측정 방식, 비교 대상과 예외, 적용 시점 또는 분류 기준을 명시합니다.
   - 시간에 따라 달라질 수 있는 정보에는 기준 연도나 날짜를 명시합니다.
   - 이미 필요한 기준이 충분하면 '기준 명확'으로 표시합니다. 표현이 있다는 이유만으로 오류로 단정하지 않습니다. 사실 확인이 필요한 기준이나 수치는 추측하지 말고 '확인 필요'로 표시합니다.
5. 발견한 항목을 다음 열을 가진 표로 보여줍니다.
   - 파일 경로와 줄 번호
   - 문제 번호 또는 ID (없으면 '없음')
   - 카테고리
   - 발견한 표현 및 해당 표현이 포함된 문제 본문 또는 선택지 원문
   - 검증 결과 (기준 명확 / 기준 보완 필요 / 확인 필요)
   - 명확히 해야 할 기준과 수정 제안 (기준이 명확하면 그 근거)
6. 검증 범위(전체 또는 지정 카테고리), 검증한 파일 수와 문제 수, 발견한 항목 수, 기준 보완이 필요한 문제 수를 함께 표시합니다. 발견한 표현이 없으면 '검증 대상에서 모호할 수 있는 비교·최상급 표현이 발견되지 않았습니다.'라고 안내합니다. 퀴즈 파일을 찾지 못했거나 검증 대상 문제가 없는 경우에는 이를 별도로 명시합니다.
7. 퀴즈 데이터 파일은 수정하지 않고 검증 결과와 수정 제안만 보고합니다.

사용 예시:
- `/quiz-validate`: 전체 문제 검증
- `/quiz-validate 과학`: `category`가 '과학'인 문제만 검증
